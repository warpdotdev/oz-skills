# Запуск сканера: запасной путь

Основной запуск описан в шаге 1 SKILL.md:
`python3 <папка скилла>/scripts/scan.py файл.txt` (текст без файла через `-`
на stdin, жанр через `--genre`, исходник для сверки через `--before`).

Если `scan.py` упал с «не хватает зависимостей», а `uvx` есть в PATH, запусти
то же через `uvx ru-humanizer` с теми же аргументами (`-` для stdin, `--genre`,
`--before`). Зависимости он поставит сам во временный кэш uv, систему не
трогает.

Не помог и он или команд нет вовсе: работай вручную. О недоступности сканера
скажи одной строкой, только если пользователь сам просил балл или аудит; как
поставить зависимости, написано в ошибке сканера и в README. Балл на глаз не
придумывай.
