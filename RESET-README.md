# Hermes UI Reset Procedure

## Overview

This procedure restores Hermes UI state files to factory defaults. It is useful when
the application exhibits visual glitches, stuck settings, or other UI issues that
persist across restarts.

## What Gets Reset

| File / Directory | Action |
|---|---|
| `native-theme.json` | Replaced with `{"themeSource": "system"}` |
| `translucency.json` | Replaced with `{"intensity": 0}` |
| `window-state.json` | Deleted (Electron recreates on next launch) |
| `Preferences` | Deleted (Electron recreates on next launch) |
| `Local State` | Deleted (Electron recreates on next launch) |
| `Local Storage\` | Cleared entirely (regenerates on next launch) |
| `Session Storage\` | Cleared entirely (regenerates on next launch) |

## Prerequisites

- **Hermes must be completely closed** before running the reset. Check the system tray.
  The script will refuse to run if `Hermes.exe` is detected.
- Ensure you have the backup directory from which to run the script.

## Steps

1. Close Hermes completely (window + system tray).
2. Open a terminal (PowerShell or cmd).
3. Run the reset script:

   ```bat
   cmd /c "<path-to-backup-folder>\apply-reset.bat"
   ```

   The script will:
   - Back up current live state to a new timestamped `backups-before-apply-*` folder.
   - Remove or clear the UI state files listed above.
   - Write the default `native-theme.json` and `translucency.json`.

4. Launch Hermes. It will regenerate fresh defaults on startup.

## Rollback

If you need to undo the reset:

1. Close Hermes completely.
2. Copy the files from the most recent `backups-before-apply-*` folder back into
   `%APPDATA%\Hermes\` (overwriting defaults).
3. Relaunch Hermes.

## Cleanup

After confirming the reset is successful and you no longer need rollback ability,
delete the backup directories:

```powershell
Remove-Item "$env:APPDATA\Hermes\backups-before-reset-*" -Recurse -Force
Remove-Item "$env:APPDATA\Hermes\backups-before-apply-*" -Recurse -Force
```

## Status

- Reset completed successfully on 2026-07-20.
- Backup directories cleaned up — no rollback data remains.
- All UI state files regenerated by Hermes on launch.

## Notes

- The `apply-reset.bat` script creates a live backup *before* clearing files, so even
  if Hermes was opened between staging and running, the intermediate state is preserved.
- The `native-theme.json` may show `"light"` or `"dark"` after launch instead of
  `"system"` — this is normal. Hermes resolves `"system"` to the actual OS preference
  and writes it back.
- No application data, saved conversations, or user content is affected by this reset.
  Only UI appearance and window state are restored.
